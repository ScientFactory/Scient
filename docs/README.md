# Documentation

Status: Active
Owner: Yaacov
Last updated: 2026-06-27
Purpose: Maps the LitRev documentation structure and where each kind of information belongs.
Doc type: Repo orientation

LitRev is currently documentation-first. This structure gives product, architecture, planning, research, development, and operations material clear homes without pretending the implementation already exists.

Start here:

- `documentation-policy.md` - documentation rules, metadata, statuses, and placement policy.
- `product/PRD.md` - canonical product direction.
- `product/product-philosophy.md` - durable product principles.
- `architecture/technology-stack.md` - current stack direction.
- `architecture/` - architecture direction, future architecture homes, and decisions.
- `design/` - future home for product design principles and UI guidance.
- `quality/` - quality principles and testing philosophy.
- `planning/` - plans that guide upcoming work.
- `research/` - external source evaluations, spikes, and raw/synthesized research.
- `development/` - development docs once code exists.
- `operations/` - operations docs once operational surfaces exist.
