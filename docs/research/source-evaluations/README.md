# Source Evaluations

Status: Active
Owner: Yaacov
Last updated: 2026-07-12
Purpose: Maps evaluations of external sources and tools that may inform PapiLab product and architecture decisions.
Doc type: Repo orientation

Use this folder for structured evaluations of external products, repositories, papers, tools, libraries, and model answers.

Current files:

- `competitive-landscape.md` - current direct competitors, substitute workflows, specialized alternatives, and integration candidates.
- `model-benchmark-map.md` - external benchmark coverage, meaning, limitations, and relevance across the candidate model portfolio.
- `model-portfolio-and-provider-routing.md` - current candidate model portfolio, distinct model roles, and the evidence needed before selection.
- `open-source-adaptation-map.md` - cross-source synthesis of open-source systems PapiLab should study, prototype, adapt, or avoid.
- `source-evaluation-template.md` - future home for the source evaluation template.

Document the source, what was inspected, what PapiLab can learn from it, what should be avoided, and what remains uncertain.

Do not mix raw source capture with final architecture decisions.
