## Document Rules

Use this file as a lightweight staging area for real UX/UI insights gathered from product discussion, source review, design review, prototypes, or implementation feedback.

Do not use this file as product truth, final UI doctrine, implementation behavior, or generic inspiration storage.

Keep entries short. Promote stable cross-product principles into `product-design-principles.md` only when they are durable enough. Keep surface-specific notes in dedicated files when a surface starts collecting enough real insight.
